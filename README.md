# 至冬列车 · 网页玩法小样（重写版）

打开 `index.html`，或 `v2/index.html`。两个入口使用同一套代码，无构建步骤、无网络依赖，支持直接打开本地文件。

触屏点按升降档；键盘 ↑/↓ 或 W/S。一按只换一档，不自动连发。Esc 暂停/继续；切到后台自动暂停。结算后可重开。

## 规则来源与文档冲突处理

本次以 `../docs/gdd.md` 的 P0 范围、`../官方列车小游戏_实现汇总.md` 的后续修订为依据。
设计拆解中的早期推导不覆盖后续明确更正。

| 规则 | 实现 | 来源 |
|---|---|---|
| 档位 | −3～+3；档位提供加速度，不是目标速度 | 实现汇总 §三 |
| 平地加速度比例 | −6 / −5 / −4 / −1 / +2 / +3 / +4 | 实现汇总 §三、仪表与加速度推导 §一；属于自洽推断，非官方源码 |
| 坡道 | 牵引力 + 环境贡献；空档也可能在下坡升速 | 实现汇总 §三环境表 |
| 限速得分 | 仅限速段按合规距离累计，5 米一批；不限速出站段不计限速维持分，末尾结清尾数，越界漏分、不倒扣 | 实现汇总 §5.2 |
| 换挡升温 | 每次 +1/4；正常每 5 秒降 1/4 | 实现汇总 §6.1 已更正早期 +1/3 |
| 过热 | 扣 200 分、档位归 0、锁 3 秒 | 实现汇总 §5.4、§6.1 |
| 过热归零 | 3 秒锁档期间归零，解除后允许换挡 | 实现汇总 §6.3 归零解锁记录；期间线性降温仅是小样展示方式 |
| 仪表 | 顶部目标速度条 + 独立半圆实际速度表；四色弧长按速度边界统一标定为 79.5°/48°/36°/16.5°（截图测量约 79°/48°/36°/17°） | 实现汇总 §四 |
| 停靠 | 最后 300 米显示横条；实际停稳后才结算 | 实现汇总 §5.1；GDD §三、§四 |
| 时间 | 只显示，不扣分，也不实现好友排行榜 | GDD §四 |

**没有作为既定事实处理的内容：** 原始资料未给出完整关卡坐标、真实 km/h 标定、限速计分单价、停靠窗口宽度和停靠计分公式。
因此 `game.js` 中的 `ROUTE` 明确是一条试行线路，不是官方关卡复刻；`RULES` 集中保存所有调参值：

- 当前线路 4200 米；限速段共 1840 米（约 44%）。中速缓坡 / 高速下坡 / 低速缓坡 / 中速上坡 / 站前慢行，准备与转场距离为 360、470、620、370 米，末尾 300 米不限速用于停靠。出站 0–240 米环境为 0、不限速。保持段环境采用 −2.5、+4.5、−3.5，使相邻合适档位的净值为 ±0.5；准备段提前使用对应坡道，提供换挡适应空间。预告提前 180–400 米。
- 加速度比例映射到 km/h/s 的倍率 8（净加速度 0.5 对应指针 6°/秒），显示量程 0～120 km/h；量程不限制实际速度，没有速度阻力项或档位终速。
- 合规每米 1 分；停车点 ±5 米，中心 200 分，按位置差线性递减；停稳阈值 0.3 km/h。
- 超过停车点 35 米则结束行程、停靠分为 0，仍然结算；不会无限驶出地图。
- 不使用旧版隐藏的两倍时间缩放；不新增擦窗、多站点、排行榜或副评分系统。

这些是跑通 P0 所需的小样参数，不宣称是原作数值。文档中的特殊限速段指针角速度、各色带非线性速度响应未精确复刻，因资料标有估测且缺少统一速度映射。

## 视觉与文件

冷蓝雪原、有限色像素场景、暖色车窗、按路段环境变化的轨道。素材使用 `../至冬列车/final/列车_240x66.png` 的本地副本 `assets/train.png`。
**车头朝右**：绘制时镜像，原始定稿素材保留。素材已内嵌到两个 HTML 入口，并显式指定尺寸；绘制读取自然尺寸，避免隐藏图片被遗漏。画布按场景容器比例调整，镜头保持列车可见，不再用 CSS cover 裁剪。起始画面有出发站，终点有独立到达站。场景随距离滚动，雪花仅是视觉装饰，不影响计分。

- `index.html`：默认入口，语义化界面结构。
- `v2/index.html`：兼容原先打开路径，与默认入口同步。
- `style.css`：响应式布局，窄屏将目标条改为纵向排列，不缩放整张固定设计稿。进度条按距离比例绘制路段：出站段灰色不限速，限速段按目标速度色带着色、标速度范围，并用白针显示当前进度；过渡段用灰色斜纹标出真实距离，当前段加白色描边。
- `game.js`：独立玩法状态与规则，浏览器和 Node 共用。
- `scene.js`：像素场景与列车绘制。
- `app.js`：输入、仪表、开始/暂停/结算界面。

## 仪表校准修正（2026-10-11）

速度色带、指针与顶部速度标记统一读取模型的显示量程和颜色边界（53、85、109 km/h）。移除手写角度导致的边界偏差，速度读数保留一位小数，并根据未取整的实际速度显示“低于限速 / 速度合规 / 超速”。超过 120 km/h 时数字继续增长、提示超出表盘量程；此量程仍不限制物理速度。速度趋势按当前档位与当前路段即时计算，静止和暂停不再显示正在减速。

## 加速度与局长校准（2026-10-11，覆盖前述早期试验参数）

用户明确：8 秒/6 秒对应净加速度大小 0.5；参考局长约 240–300 秒。线性校准采用 `净值 = 档位力 + 环境贡献`、`指针角速度 = 净值 × 12 °/秒`。在自设 120 km/h / 180° 量程下，真实速度变化率为 `净值 × 8 km/h/s`；模型积分速度与距离，场景和指针读取同一状态，不单独加速动画。绿色色带宽 48°、橙黄色带宽 36°，净值 ±0.5 的完整遍历为 8 秒/6 秒。合法速度范围与色带全宽区分：例如绿带 53–85，当前限速目标 53–84。

当前 4200 米路线参考操作耗时约 286.6 秒、所有 1840 米限速路段合规、零过热、停车误差约 2.8 米。仅为可行性与节奏参考，不设置强制时限，不保证不同驾驶策略同样耗时。21 项模型与绘制测试通过；加速度校准后的手机手感待试玩。

## 蓝区代偿（2026-10-11，覆盖统一倍率规则）

用户确认平地 0 档净值 −1 在蓝区仍只偏转约 −6°/秒。蓝区响应倍率现为其他色带的一半：蓝区净值 × 6°/秒、其余色带净值 × 12°/秒。采用正负对称作为本项目规则；不是单独给指针加视觉缓动。速度、距离、计分和场景共享修正后的物理状态；跨蓝/绿边界和停车瞬间按事件分段积分，停靠参考操作使用分段刹车距离。蓝区净值 −1 遍历约 13.25 秒，绿/橙区净值 ±0.5 的 8 秒/6 秒不变。

最新参考操作约 296.6 秒、1840 米限速全合规、零过热、停车误差约 1.5 米，替代前述旧轨迹数字。22 项测试通过。
