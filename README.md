# 至冬列车 · 网页玩法小样（重写版）

打开 `index.html`，或 `v2/index.html`。两个入口使用同一套代码，无构建步骤、无网络依赖，支持直接打开本地文件。

触屏点按升降档；键盘 ↑/↓ 或 W/S。一按只换一档，不自动连发。Esc 暂停/继续；切到后台自动暂停。结算后可重开。

## 规则来源与文档冲突处理

本次以 `../docs/gdd.md` 的 P0 范围、`../官方列车小游戏_实现汇总.md` 的后续修订为依据。
设计拆解中的早期推导不覆盖后续明确更正。

| 规则 | 实现 | 来源 |
|---|---|---|
| 档位 | −3～+3；档位提供加速度，不是目标速度 | 实现汇总 §三 |
| 平地加速度比例 | −6 / −5 / −4 / −1 / +2 / +3 / +4 | 实现汇总 §三、仪表与加速度推导 §一；属于自洽推断，非官方源码 |
| 坡道 | 牵引力 + 环境贡献；空档也可能在下坡升速 | 实现汇总 §三环境表 |
| 限速得分 | 仅限速段按合规距离累计，5 米一批；不限速出站段不计限速维持分，末尾结清尾数，越界漏分、不倒扣 | 实现汇总 §5.2 |
| 换挡升温 | 每次 +1/4；正常每 5 秒降 1/4 | 实现汇总 §6.1 已更正早期 +1/3 |
| 过热 | 扣 200 分、档位归 0、锁 3 秒 | 实现汇总 §5.4、§6.1 |
| 过热归零 | 3 秒锁档期间归零，解除后允许换挡 | 实现汇总 §6.3 归零解锁记录；期间线性降温仅是小样展示方式 |
| 仪表 | 顶部目标速度条 + 独立半圆实际速度表；四色弧长 79°/48°/36°/17° | 实现汇总 §四 |
| 停靠 | 最后 100 米显示横条；实际停稳后才结算 | 实现汇总 §5.1；GDD §三、§四 |
| 时间 | 只显示，不扣分，也不实现好友排行榜 | GDD §四 |

**没有作为既定事实处理的内容：** 原始资料未给出完整关卡坐标、真实 km/h 标定、限速计分单价、停靠窗口宽度和停靠计分公式。
因此 `game.js` 中的 `ROUTE` 明确是一条试行线路，不是官方关卡复刻；`RULES` 集中保存所有调参值：

- 线路 1060 米，车站出发 / 上坡 / 下坡 / 站前平地 / 进站，各段之间加入 40 米不限速过渡距离；只使用文档环境值 0、−0.5、+2.5。用户明确：初始从车站出发、环境加速度为 0、不限速；出站段 0–180 米不显示目标速度框，也不计限速段维持分。
- 加速度比例映射到 km/h/s 的倍率 1.6，显示量程 0～120 km/h；量程不限制实际速度，没有速度阻力项或档位终速。
- 合规每米 1 分；停车点 ±5 米，中心 200 分，按位置差线性递减；停稳阈值 0.3 km/h。
- 超过停车点 35 米则结束行程、停靠分为 0，仍然结算；不会无限驶出地图。
- 不使用旧版隐藏的两倍时间缩放；不新增擦窗、多站点、排行榜或副评分系统。

这些是跑通 P0 所需的小样参数，不宣称是原作数值。文档中的特殊限速段指针角速度、各色带非线性速度响应未精确复刻，因资料标有估测且缺少统一速度映射。

## 视觉与文件

冷蓝雪原、有限色像素场景、暖色车窗、按路段环境变化的轨道。素材使用 `../至冬列车/final/列车_240x66.png` 的本地副本 `assets/train.png`。
**车头朝右**：绘制时镜像，原始定稿素材保留。素材已内嵌到两个 HTML 入口，并显式指定尺寸；绘制读取自然尺寸，避免隐藏图片被遗漏。画布按场景容器比例调整，镜头保持列车可见，不再用 CSS cover 裁剪。起始画面有出发站，终点有独立到达站。场景随距离滚动，雪花仅是视觉装饰，不影响计分。

- `index.html`：默认入口，语义化界面结构。
- `v2/index.html`：兼容原先打开路径，与默认入口同步。
- `style.css`：响应式布局，窄屏将目标条改为纵向排列，不缩放整张固定设计稿。进度条按距离比例绘制路段：出站段灰色不限速，限速段按目标速度色带着色、标速度范围，并用白针显示当前进度；过渡段用灰色斜纹标出真实距离，当前段加白色描边。
- `game.js`：独立玩法状态与规则，浏览器和 Node 共用。
- `scene.js`：像素场景与列车绘制。
- `app.js`：输入、仪表、开始/暂停/结算界面。

## 进入提示与环境画面（2026-10-11）

- 进入限速段时，仪表盘上方出现同色小提示，显示路段名与速度范围，持续 4 秒；过热提示仍独立显示。
- 各阶段之间真实增加 40 米不限速过渡，环境加速度为 0，不计限速维持分。这是当前小样的间隔参数；全程由 900 米增加到 1060 米。
- `terrainAt()` 读取同一份 `ROUTE.environment`：负值上坡、正值下坡、0 为平地。积分生成连续轨道高度；列车按所在地轨道倾角绘制，树木及路基跟随高度，不再把所有路段画成同一个斜面。
- 视觉坡度采用符号保持的显示映射，不宣称环境加速度等于真实坡度角。上坡/下坡/平地的回归图见 `../records/prototype/*-terrain.png`。

## 截图参考与速度表现（2026-10-11）

- 档位显示及操作保留。温度表改为总弧长 210°，角度依据用户明确指定；旧文档提供正常白色、偏高橙色、过热冷却红色的双通道规则（实现汇总 §6.4–6.6）。弧长随温度变化，图标颜色按状态切换，过热色不因温度降到 75% 以下而提前恢复。
- 进度条移到顶部，参考截图采用细轨道、限速色块、不限速留空，以及金色菱形/三角位置指示；实际 40 米过渡距离保留。
- 距下一限速段 80 米内，场景上方出现“即将进入限速区间，请保持车速”的预告，标出距离与目标范围。80 米是小样参数；进入后预告消失，仪表上方的当前区间半透明色带持续显示。
- 距离到场景位移的比例由 2.1 改为 8 px/m，仅改善视觉辨识，不改变速度、加速度或计分。镜头跟随列车，因此车体居中；轨枕、车轮和景物全部按实际行驶距离运动，速度不同则滚动速率不同，停车后停止。雪花是天气，不表示列车移动。
- 新增 30/60 km/h 画面位移对比及静止回归，温度与新界面的 DOM 检查通过；本机仍未进行真实手机浏览器截图验收。

用户手机试玩反馈：当前显示正常。总分下限为 0，过热最多扣除当前已有分数；提示和结算扣分记录使用实际扣除量。
